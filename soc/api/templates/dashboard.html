How it works

Learn normal

Each user's and host's usual sign-ins, devices, files and websites form a personal baseline.

Spot changes

Sigma rules catch known attack patterns; machine learning catches behaviour unlike the baseline.

Score & group

Detections add up into a risk score per user or host; the riskiest become incidents.

Explain & respond

A playbook rebuilds the attack story and proposes MITRE D3FEND responses for a lead to approve.
